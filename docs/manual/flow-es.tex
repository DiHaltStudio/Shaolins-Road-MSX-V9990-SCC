\begin{enumerate}
\item \textbf{Mensaje de arranque.} En la pantalla del propio MSX, \texttt{KONAMI 1985 / DIHALT STUDIO 2026 / V9990 found !} durante dos segundos.
\item \textbf{Logotipo de DiHalt.} Se muestra cuatro segundos; no se puede saltar.
\item \textbf{Portada.} La ilustraci\'on a pantalla completa. Pulsa cualquier tecla o cualquier direcci\'on o bot\'on del joystick para continuar (tambi\'en sigue sola a los diez segundos).
\item \textbf{Pantalla de t\'itulo.} \texttt{PRESS START}, \texttt{1 HARD 2 MEDIUM} y la informaci\'on de las vidas extra. Pulsa \key{1}, \key{ESPACIO} o el bot\'on \key{A} del joystick para empezar en modo \textbf{dif\'icil}, o \key{2} o el bot\'on \key{B} del joystick para empezar en modo \textbf{medio}. Si esperas, el juego muestra una demostraci\'on y la tabla de r\'ecords, y vuelve al t\'itulo.
\item \textbf{El juego}: cinco fases, despu\'es las mismas cinco otra vez, algo m\'as dif\'iciles, y as\'i sucesivamente.
\end{enumerate}

Cuando pierdes la \'ultima vida aparece \texttt{GAME OVER}. Si tu puntuaci\'on est\'a entre las ocho mejores, escribes tus tres iniciales; despu\'es vuelve la pantalla de t\'itulo.
